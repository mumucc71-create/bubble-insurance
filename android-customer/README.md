# 버블보험 고객 Android 앱 0.1.0

기존 invite.html 고객 화면을 그대로 앱에 포함한 다운로드 호환성 시험용 앱입니다. 기존 웹페이지와 설계사 화면은 수정하지 않습니다.

## 구현
- 고객 홈: 기존 네이비/연한 블루 디자인, 하단 메뉴, 보험금 청구 → 보장분석 → 보험설계, 설계 클릭 시 예산 표시.
- 진료정보 연결: 저장 동의 → 앱 내부 WebView로 심평원 공식 페이지 열기.
- HTTPS hira.or.kr 다운로드 요청에 한해 앱 전용 내부 저장소로 수신. 다운로드 폴더 전체 접근 권한 없음.
- 크기 제한 30MB, 시간 제한, 호스트 제한, 파일 시그니처 검사, 리디렉션 검사, 실패 시 부분 파일 삭제.
- PDF 기록 보기, 페이지 이동, 기록 삭제. ZIP/XLS 형식은 저장만 하며 미지원 상태를 표시.
- 마이 메뉴에서 기기에 받은 기록 확인.

## 아직 검증/구현되지 않은 항목
- 실제 본인 인증은 본인 기기에서 검증해야 합니다. 심평원 WebView 지원 여부, 인증 앱 복귀, 팝업 및 다운로드 형태는 미확인입니다.
- POST/blob URL 다운로드, 별도 호스트, 암호 PDF는 지원되지 않을 수 있습니다. 실패를 완료로 표시하지 않습니다.
- 서버 자동 업로드, 고객 식별/담당 설계사 연결, 민감정보 동의·권한, 데이터 추출 및 보험 내역 조회는 아직 구현하지 않았습니다. 현재 서버 전송 코드는 없습니다.
- 심평원 자동화된 조회·전송 관련 협의 요건은 별도 확인해야 합니다.
- 보험금 청구/보장분석 등 기존 미연결 기능은 준비 중으로 표시합니다.

## 빌드
JDK 17 이상, Android SDK 35, Gradle 8.10.2.
`gradle assembleDebug`로 시험용 APK를 생성합니다.
배포용 서명키는 별도로 관리해야 하며 debug APK는 공개 고객 배포용이 아닙니다.
앱을 삭제하면 기기에 받은 기록도 삭제됩니다. 백업은 비활성화되어 있습니다.

## 0.1.1
인증용 새 창 지원, 인증 앱 실행 시 인텐트 정리, 사이트 연결 상태 및 재시도, 홈 뒤로가기 수정. 실제 심평원 인증 이후 단계는 여전히 실기기 검증 필요.

## 0.1.2
진료정보 연결 버튼에서 공식 조회 안내와 로그인 방식 선택을 자동으로 진행하여 간편인증 창을 엽니다. 인증수단 선택, 본인정보 입력, 동의, 인증 요청은 고객이 수행합니다. 페이지 구조 변경 시 수동 버튼은 그대로 사용 가능합니다.

## 0.1.3
고객 요청에 따라 간편인증 창에서 카카오톡을 기본 선택합니다. 이름·생년월일·휴대폰 번호, 약관 동의 및 인증 요청은 자동 처리하지 않습니다. 다른 인증수단으로 변경할 수 있습니다. 실기기 검증은 필요합니다.

## 0.1.4
기존 홈 디자인은 그대로 두고 인증 준비 화면에 승인된 눈웃음 버블이를 표시합니다. 둥실 움직이며 누르면 짧은 톡 소리와 방울 효과가 나옵니다. 동작 줄이기 설정을 반영하며 자동 소리는 없습니다. 카카오 입력 화면 준비 확인 후 가림막을 제거하고 45초 지연 시 안내합니다. 실기기 인증 완료·다운로드는 여전히 검증 필요합니다.

## 0.1.5
심평원 페이지에서 명확한 동의 라벨과 체크/라디오 상태를 인식하면 큰 글씨 안내, 스크롤 방향, 항목 테두리를 표시합니다. 필수 여부를 추측하거나 전체/선택 동의를 유도하지 않으며 아무 항목도 자동 클릭하지 않습니다. 명확히 식별되지 않는 버튼은 강조하지 않습니다. 안내는 웹페이지 바깥에 배치하며 입력값이나 진료내용을 서버로 보내지 않습니다. 인증 이후 실제 심평원 페이지 호환성은 검증 전입니다.
